# Sales Performance Analysis

## Project Overview

This project focuses on analyzing sales data to identify business trends, evaluate sales performance, and gain insights into products, customers, and geographical performance.

The analysis was conducted using SQL and Power BI.

## Tools & Technologies

- **SQL (MySQL):** Data exploration, data quality checks, data analysis, JOINs, aggregations, and calculations.
- **Power BI:** Data visualization, interactive dashboards, and KPI analysis.

## Dataset

The project uses three datasets:

- `orders.csv` – Order information, including dates, statuses, quantities, prices, and shipping.
- `products.csv` – Product details, categories, and unit costs.
- `customers.csv` – Customer information, including country and customer plan.

## SQL Analysis

The SQL analysis covers:

- Dataset exploration and record counts.
- Data quality checks.
- Order status analysis and distribution.
- Monthly and annual revenue trends.
- Revenue and order analysis by country.
- Average order value by country.
- Revenue by product category.
- Top 10 products by revenue.
- Gross profit by product category.

## Power BI Dashboard

The interactive Power BI dashboard consists of two pages:

**1. Sales Overview**
- Key performance indicators (KPIs).
- Monthly sales trends.
- Order status breakdown.
- Revenue by product category.
- Revenue by country.
- Interactive filters.

**2. Product & Customer Analysis**
- Top 10 products by revenue.
- Revenue by customer plan.
- Quantity sold by product category.
- Top 10 customers by revenue.
- Interactive slicers.

## Key Performance Indicators

- Delivered Revenue
- Delivered Gross Profit
- Total Orders
- Delivered Orders
- Delivery Rate
- Customers with Orders
- Delivered Average Order Value (AOV)

## Project Files

- `sales_analysis.sql` – SQL queries used for the analysis.
- `Sales_Performance_Analysis.pbix` – Interactive Power BI dashboard.
- `Dataset/` – Source CSV files.

## Conclusion

This project demonstrates practical skills in SQL data analysis and Power BI dashboard development. It provides insights into sales performance, customer behavior, product performance, and geographical trends.
